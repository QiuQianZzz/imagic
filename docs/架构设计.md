# Imagic 架构设计

## 1. 技术栈

| 层面 | 技术选型 |
|------|----------|
| 框架 | Flutter 3.44.2 (Windows Desktop) |
| 语言 | Dart 3.9+ |
| 状态管理 | Provider |
| 图像处理 | image (^4.5.0) — 纯 Dart 图像编解码与处理 |
| 文件选择 | file_picker (^8.1.6) |
| 路径工具 | path + path_provider |

## 3. 架构分层

```
┌─────────────────────────────────────────────────┐
│                 Presentation Layer                │
│   (Screens / Widgets / Dialogs / Overlays)       │
│           ←→  Provider (ChangeNotifier)          │
├─────────────────────────────────────────────────┤
│                  Service Layer                    │
│   FileService | ImageCodecService | ...          │
├─────────────────────────────────────────────────┤
│                   Engine Layer                    │
│   ImageProcessor | ColorAdjustment | Filters     │
│   Transforms | EditAction Pipeline               │
├─────────────────────────────────────────────────┤
│               Dependencies / I/O                  │
│   image (pub) | file_picker | dart:io            │
└─────────────────────────────────────────────────┘
```

### 3.1 数据流

```
用户操作 → Widget → Provider.setXxx() → Service/Engine
                                    ↓
                    Provider.notifyListeners()
                                    ↓
                        Widget 重建更新 UI
```

以裁剪操作为例：

```
用户拖拽裁剪框 → CropTool 更新 Rect
         ↓
EditState.setCropRect(rect)  
         ↓
ImageProcessor.previewCrop(rect) → 生成预览图
         ↓
notifyListeners() → EditCanvas 重建显示预览
         ↓
用户点击「应用裁剪」
         ↓
EditState.applyAction(CropAction(rect))
    ├── EditHistory.push(CropAction)
    ├── ImageProcessor.apply(CropAction) → 更新工作图
    └── notifyListeners() → 画布更新
```

### 3.2 撤销/重做数据流

```
EditHistory
├── List<EditAction> _actions          # 操作列表
├── int _currentIndex                  # 当前状态指针
│
├── push(action)                       # 执行新操作
│   ├── 丢弃 _currentIndex 之后的操作
│   ├── 执行 action.apply(currentImage)
│   ├── _actions.add(action)
│   └── _currentIndex++
│
├── undo()                             # 撤销
│   ├── _currentIndex--
│   ├── 从原始图重新应用到 _currentIndex
│   └── 返回当前结果
│
└── redo()                             # 重做
    ├── _currentIndex++
    ├── 从原始图重新应用到 _currentIndex
    └── 返回当前结果
```

## 4. 核心模块设计

### 4.1 图像处理引擎 (Engine)

```
ImageProcessor
│
├── 属性
│   ├── Image originalImage        # 原始图像（不可变）
│   └── Image workingImage         # 当前工作图（编辑后的缓存）
│
├── 变换方法
│   ├── crop(Rect) → Image
│   ├── rotate(double angle) → Image
│   ├── flip(Axis) → Image
│   └── resize(int width, int height) → Image
│
├── 色彩方法
│   ├── adjustBrightness(double) → void
│   ├── adjustContrast(double) → void
│   ├── adjustSaturation(double) → void
│   └── adjustHue(double) → void
│
├── 滤镜方法
│   ├── applyBlur(double radius) → void
│   ├── applySharpen(double amount) → void
│   ├── applyGrayscale() → void
│   ├── applyInvert() → void
│   ├── applyEmboss() → void
│   ├── applyEdgeDetect() → void
│   ├── applyPixelate(int blockSize) → void
│   └── applyConvolution(List<double> kernel) → void
│
└── 渲染
    ├── getPreviewImage() → Image   # 当前操作预览
    └── getFinalImage() → Image     # 合并所有操作和叠加层
```

### 4.2 叠加层系统

```
OverlayLayer (abstract)
├── Rect bounds                     # 边界
├── void render(Canvas, Size)       # 渲染到画布
├── bool hitTest(Offset)            # 命中检测
└── void moveBy(Offset)             # 移动

DrawPathLayer extends OverlayLayer
├── List<Offset> points             # 路径点
├── Color color                     # 颜色
├── double strokeWidth              # 粗细
└── double opacity                  # 透明度

ShapeLayer extends OverlayLayer
├── ShapeType type                  # 矩形/椭圆/箭头
├── Rect rect                       # 位置大小
├── Color fillColor                 # 填充色
├── Color strokeColor               # 描边色
└── double strokeWidth              # 描边粗细

TextLayer extends OverlayLayer
├── String text                     # 文字
├── Offset position                 # 位置
├── double fontSize                 # 字号
├── Color color                     # 颜色
└── String fontFamily               # 字体
```

### 4.3 编解码服务

```
ImageCodecService (单例)
│
├── decodeFromFile(String path) → Image
│   ├── 读取文件字节
│   ├── 根据扩展名选择解码器
│   ├── 解码为 Image 对象
│   └── 缓存原始文件字节
│
├── encodeToBytes(Image, Format, Quality) → Uint8List
│   ├── JPEG: encodeJpg(image, quality: 1-100)
│   ├── PNG:  encodePng(image, level: 0-9)
│   ├── BMP:  encodeBmp(image)
│   ├── WebP: encodeWebp(image, quality: 1-100)
│   └── 其他: 对应编码器
│
├── saveToFile(Image, String path, Format, Quality) → void
│
├── getImageInfo(String path) → ImageInfo
│   ├── 尺寸 (width × height)
│   ├── 格式
│   ├── 文件大小
│   └── (可选) EXIF 信息
│
└── dispose()                      # 释放缓存
```

### 4.4 文件服务

```
FileService
│
├── listDirectory(String path) → List<FileEntity>
│   ├── 过滤出支持的图片格式
│   └── 返回文件列表（排序：名称/日期/大小）
│
├── getAdjacentFiles(String currentPath) → (List<String>, int index)
│   ├── 获取同目录相邻图片
│   └── 返回文件列表和当前索引
│
├── openFileDialog() → String?            # 打开文件对话框
├── saveFileDialog(String defaultName) → String?  # 保存对话框
├── readFileBytes(String path) → Uint8List
└── writeFileBytes(String path, Uint8List bytes) → void
```

## 5. 状态管理设计

### 5.1 Provider 结构

```dart
MultiProvider(
  providers: [
    // 服务层（全局单例）
    Provider<FileService>(create: (_) => FileService()),
    Provider<ImageCodecService>(create: (_) => ImageCodecService()),
    Provider<RecentFilesService>(create: (_) => RecentFilesService()),

    // 状态层
    ChangeNotifierProvider<BrowserState>(
      create: (_) => BrowserState(),
    ),
    ChangeNotifierProvider<ViewerState>(
      create: (_) => ViewerState(),
    ),
    ChangeNotifierProvider<EditState>(
      create: (_) => EditState(),
    ),
    ChangeNotifierProvider<ExportState>(
      create: (_) => ExportState(),
    ),
  ],
  child: MaterialApp(...),
)
```

### 5.2 状态类职责

| State | 关键属性 | 职责 |
|-------|---------|------|
| `BrowserState` | currentDir, files, selectedIndex | 文件浏览、目录导航 |
| `ViewerState` | currentFile, scale, offset, rotation | 查看模式控制 |
| `EditState` | actions[], currentIndex, toolType, overlays[] | 编辑操作、工具切换 |
| `ExportState` | format, quality, targetSize, outputPath | 导出参数配置 |

## 6. 启动流程

```
main() → CommandLine.arguments → 提取文件路径
    ↓
App(initialFile: path)
    ↓
MaterialApp → onGenerateRoute
    ↓
MultiProvider.init → 初始化服务
    ↓
ViewerScreen(initialFile)
    ├── 有文件路径 → FileService.listDirectory → FileService.readFile
    │   └── ImageCodecService.decode → Image → ViewerState
    └── 无文件路径 → 显示空状态（欢迎界面/打开文件提示）
```


## 8. 线程模型

- **主线程（UI Isolate）**：所有 UI 渲染和 Provider 状态更新
- **图片解码/编码**：使用 `compute()` 或 `Isolate.run()` 在后台 Isolate 执行，避免阻塞 UI
- **文件 I/O**：文件读写使用 `dart:io` 异步 API

```dart
// 在后台 Isolate 中处理大图编解码
Future<Image> decodeAsync(Uint8List bytes) async {
  return Isolate.run(() => decodeImage(bytes));
}
```
