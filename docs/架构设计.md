### 数据流

```
用户操作 → Widget → State.setXxx() → Service
                                ↓
                State.notifyListeners()
                                ↓
                  Widget 重建（Consumer / Selector）
```

以打开图片为例：

```
用户拖入文件 → DropTarget.onDragDone
         ↓
ViewerState.openFile(path)
    ├── ImageCodecService.readBytes(path)
    ├── 按扩展名分流：
    │   ├── SVG → 直接保存字节，解析 viewBox/width/height
    │   └── 其他 → 字节头判断 PNG/JPEG/WebP，解析宽高
    ├── FileService.getAdjacentFiles(path) → 填充 _files
    └── notifyListeners() → ImageCanvas 重建显示
```

## 4. 核心模块设计

### 4.1 图片编解码服务

`ImageCodecService` 为单例，所有耗时操作通过 `Isolate.run` 在后台执行，避免阻塞 UI。

```
ImageCodecService
├── readBytes(path) → Uint8List         # 直接读取原始字节（SVG / PNG 用）
├── decodeToPng(path) → Uint8List       # 读取 + 在 Isolate 中解码重编码为 PNG
└── bytesToPng(bytes) → Uint8List       # 已读字节 → Isolate 解码 → PNG 字节
```

加载策略（在 `ViewerState.openFile` 中分流）：

| 格式                                     | 加载方式                                           | 原因                                  |
| ---------------------------------------- | -------------------------------------------------- | ------------------------------------- |
| SVG                                      | 直接读取字节，由 flutter_svg 渲染                  | 矢量格式无需光栅化                    |
| PNG                                      | 直接读取字节，由 Flutter 引擎的 C++ PNG 解码器处理 | 引擎原生解码速度最快                  |
| 其他（JPEG / BMP / WebP / TGA / PPM 等） | 在 Isolate 中用 image 包解码并重编码为 PNG         | 避免 Flutter 在 UI 线程上执行慢速解码 |

宽高解析：在主线程读取字节头快速提取（不依赖完整解码）：

- PNG：解析 IHDR 块（偏移 16/20 各 4 字节大端）
- JPEG：扫描 SOF0/SOF1/SOF2 段
- WebP：遍历 RIFF 块定位 VP8 / VP8L / VP8X
- SVG：正则匹配 viewBox 或 width/height 属性

### 4.2 文件服务

```
FileService
├── openFileDialog() → String?            # 调用 file_picker，限定支持的扩展名
├── listDirectory(dirPath) → List<ImageFile>  # 遍历目录，过滤图片，按名称排序
├── getAdjacentFiles(currentPath) → List<ImageFile> # 同目录所有图片
└── extensionOf(path) → String            # 小写扩展名（静态方法）
```

### 4.3 设置服务与状态

`SettingsService` 负责将设置写入 `SharedPreferences`，`SettingsState` 包装为 `ChangeNotifier` 暴露给 UI。

持久化字段：

| 字段               | 类型                    | 默认值         | 说明                                       |
| ------------------ | ----------------------- | -------------- | ------------------------------------------ |
| themeMode          | int (ThemeMode index)   | 0 (system)     | 主题模式                                   |
| seedColor          | int (ARGB)              | 0xFF5B8DEF     | 主题种子色                                 |
| customSeedColors   | List\<int\>             | []             | 用户自定义种子色                           |
| windowStyle        | int (WindowStyle index) | 0 (windows)    | 窗口控件样式                               |
| imageBackground    | String (enum name)      | 'checkerboard' | 图片背景类型（按 name 存储以兼容新增枚举） |
| showNavBarArrows   | bool                    | true           | 顶部导航栏左右切换按钮                     |
| showNavBarOpen     | bool                    | true           | 顶部导航栏打开按钮                         |
| showFloatingArrows | bool                    | true           | 查看区悬浮导航按钮                         |
| shortcutBindings   | JSON Map\<String, int\> | {}             | 自定义快捷键绑定（actionId → keyId）       |

`SettingsState` 维护快捷键 `LogicalKeyboardKey` 查询缓存，避免每次按键事件都遍历 `LogicalKeyboardKey.knownLogicalKeys`。

### 4.4 窗口与全屏控制

窗口操作集中在 [window_controls.dart](file:///d:/Desktop/flutter/imagic/lib/core/utils/window_controls.dart)，UI 组件不直接依赖 `window_manager`：

```
window_controls.dart
├── windowMaximizedNotifier   # ValueNotifier<bool>，启动时同步初值
├── windowMinimize()
├── windowToggleMaximize()
├── windowClose()
└── windowStartDragging()
```

```
fullscreen.dart
├── fullscreenNotifier        # ValueNotifier<bool>
├── toggleFullscreen()        # 用 maximize/unmaximize 模拟全屏
├── onWindowMaximized()       # 由 ViewerScreen 的 WindowListener 调用
└── onWindowUnmaximized()
```

**全屏与最大化分离设计**：

- `fullscreenNotifier` 与 `windowMaximizedNotifier` 独立维护
- `_fullscreenBusy` 标志区分「全屏触发的 maximize」与「用户主动 maximize」
- 仅当 `_fullscreenBusy=true` 时，`onWindowMaximized` 才置 `fullscreenNotifier=true`，避免用户正常最大化窗口时误隐藏菜单栏
- 选用 `maximize()` 而非 `setFullScreen(true)` 的原因：后者退出时窗口瞬间弹回且闪现原生标题栏，`maximize` 进出都有平滑动画；代价是任务栏仍可见

### 4.5 查看器动画控制器

`_AnimatedTransformationController`（位于 [viewer_screen.dart](file:///d:/Desktop/flutter/imagic/lib/features/viewer/ui/viewer_screen.dart)）继承自 `TransformationController`，拦截 `value` setter：

- **平移操作**（缩放分量未变）：直接透传，无动画
- **缩放操作**：通过 `_withCenterFocal` 计算以视口中心为焦点的目标矩阵，播放 200ms `easeOutCubic` 动画
- `animateTo(target)`：显式触发动画（菜单项、重置按钮使用）
- 内部 `_internal` 标志防止动画驱动自身的 setter 被重复触发

`_withCenterFocal` 通过当前矩阵反推视口中心在图片坐标系中的位置，再按新缩放重新计算平移分量，保证缩放前后视口中心点不变。

### 4.6 单实例 + 文件关联 + 自启动

Windows 系统集成相关模块，三套分发方式（Inno Setup EXE / MSIX / 绿色版）共用同一套注册表结构。

#### 4.6.1 单实例与外部文件打开

采用 **Mutex + Named Pipe + MethodChannel** 三段式通信：

```
第二实例启动
    ↓ CreateMutexW 检测到已存在
    ↓ 通过命名管道把文件路径发给主实例
    ↓ 退出
主实例的 Pipe 服务线程
    ↓ ReadFile 收到路径
    ↓ PostMessage(kWM_OPEN_EXTERNAL_FILE, heap_path) 投递到 UI 线程
    ↓ GetMessage 取出后 delete[] 回收内存
FlutterWindow.OnExternalFileOpen(path)
    ↓ MethodChannel("imagic/single_instance").invokeMethod("onExternalFileOpen", path)
Dart SingleInstanceHandler
    ↓ 若 ViewerScreen 已注册回调 → 立即派发
    ↓ 否则缓存到 _pendingPaths，待注册后 flush
ViewerScreen._handleExternalFile → _openFromPath
    ↓ 走与菜单/拖拽相同的统一调度入口
```

涉及文件：

- [windows/runner/main.cpp](file:///d:/Desktop/flutter/imagic/windows/runner/main.cpp)：Mutex 检测、Pipe 服务线程、第二实例路径转发
- [windows/runner/flutter_window.cpp](file:///d:/Desktop/flutter/imagic/windows/runner/flutter_window.cpp)：MethodChannel 创建与路径推送
- [lib/core/services/single_instance_handler.dart](file:///d:/Desktop/flutter/imagic/lib/core/services/single_instance_handler.dart)：Dart 端 MethodChannel 监听与回调注册

关键设计：

- 主窗口通过窗口类名 `Imagic` 查找（[win32_window.cpp](file:///d:/Desktop/flutter/imagic/windows/runner/win32_window.cpp) 的 `kWindowClassName`），不受运行时改标题影响
- `OnDestroy` 中先置空 channel 指针再 delete，避免关闭过程中收到外部文件路径导致 UAF
- Mutex 创建失败的极端情况下保守按主实例继续启动，避免应用无法打开

#### 4.6.2 文件关联与开机自启动

注册表为**唯一数据源**，不持久化到 SharedPreferences：

```
读取（启动时）：
  SettingsService._loadSystemIntegration()
    → WindowsRegistry.isFileAssociationRegistered()
    → WindowsRegistry.isAutoStartEnabled()

写入（用户切换开关）：
  SettingsState.setFileAssociation(value)
    → WindowsRegistry.registerFileAssociation()  // 返回 bool
    → 失败：以注册表真实状态回滚内存值，不持久化
    → 成功：更新内存值 + save()
```

注册表结构（三套分发方式完全对齐）：

| 用途 | 路径 | 值名 | 值 |
| --- | --- | --- | --- |
| ProgId 命令 | `HKCU\Software\Classes\Imagic.Image\shell\open\command` | (默认) | `"<exe>" "%1"` |
| ProgId 图标 | `HKCU\Software\Classes\Imagic.Image\DefaultIcon` | (默认) | `"<exe>",0` |
| 扩展名映射 | `HKCU\Software\Classes\.<ext>` | (默认) | `Imagic.Image` |
| 开机自启 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` | `Imagic` | `"<exe>"` |

涉及文件：

- [lib/core/utils/windows_registry.dart](file:///d:/Desktop/flutter/imagic/lib/core/utils/windows_registry.dart)：注册表读写工具，所有写入方法返回 `bool`
- [lib/features/settings/providers/settings_state.dart](file:///d:/Desktop/flutter/imagic/lib/features/settings/providers/settings_state.dart)：`setFileAssociation` / `setAutoStart` 返回 `Future<bool>` 供 UI 层判断
- [windows/packaging/inno_setup.iss](file:///d:/Desktop/flutter/imagic/windows/packaging/inno_setup.iss)：Inno 安装脚本，Tasks 默认勾选文件关联 + 自启动

关键设计：

- 写入失败时 State 层回滚内存值，UI 开关自动弹回原位，保证 UI 与系统真实状态一致
- 所有写入仅落 HKCU，不需要管理员权限
- 写入后调用 `SHChangeNotify(SHCNE_ASSOCCHANGED, ...)` 通知资源管理器刷新

#### 4.6.3 已知限制（后续待实现）

- **设置开关失败无 UI 反馈**：`SettingsState.setFileAssociation` / `setAutoStart` 已返回 `Future<bool>` 表示成功失败，但 UI 层 [general_section.dart](file:///d:/Desktop/flutter/imagic/lib/features/settings/ui/sections/general_section.dart) 当前丢弃返回值。后续应在 `onChanged` 回调中检查返回值，失败时通过 `ScaffoldMessenger.showSnackBar` 提示用户（如"文件关联设置失败，请检查权限"）。

#### 4.6.4 关于"设为默认图片查看器"

文件关联开关只写 ProgId 和扩展名默认值，但 Windows 8+ 起文件关联有优先级链：

1. `HKCU\...\Explorer\FileExts\.<ext>\UserChoice`（最高，含 Hash 校验）
2. `HKCU\Software\Classes\.<ext>`（开关写这里）
3. `HKLM\Software\Classes\.<ext>`（系统级）

对于**已被其他应用占用**的扩展名（UserChoice 已被写入），程序无法直接覆盖：

- 直接写 UserChoice → 被 Hash 校验拒绝并清除
- `SHOpenWithDialog` 程序化调用 → 不可靠，Hash 同样不通过
- `ms-settings:defaultapps` → 仅打开系统设置页面，用户仍需逐个点击扩展名

因此**应用内不提供"设为默认"按钮**，依赖两条路径：

1. **未设置过默认的扩展名**：开关打开后双击直接用 Imagic 打开
2. **已被占用的扩展名**：用户首次双击时在系统"打开方式"对话框选 Imagic + 勾选"始终使用"

**MSIX 后续路线**：未来走 MSIX 分发时，在 [pubspec.yaml](file:///d:/Desktop/flutter/imagic/pubspec.yaml) 的 `msix_config` 声明 `file_extension`，系统安装时会自动询问用户"是否设为默认图片查看器"，体验对齐商业应用（这是 MSIX 相对 EXE/绿色版的核心优势之一）。

## 5. Provider 结构

```dart
MultiProvider(
  providers: [
    Provider<FileService>(create: (_) => FileService()),
    Provider<ImageCodecService>(create: (_) => ImageCodecService()),
    ChangeNotifierProvider<SettingsState>(create: (_) => SettingsState(settings)),
    ChangeNotifierProvider<BrowserState>(create: (_) => BrowserState()),
    ChangeNotifierProvider<ViewerState>(create: (_) => ViewerState()),
  ],
  child: Selector<SettingsState, ({ThemeMode themeMode, int seedColor})>(
    builder: (context, snapshot, _) => MaterialApp(
      theme: AppTheme.light(snapshot.seedColor),
      darkTheme: AppTheme.dark(snapshot.seedColor),
      themeMode: snapshot.themeMode,
      home: ViewerScreen(initialFile: initialFile),
    ),
  ),
)
```

| State           | 关键属性                                                                  | 职责                                 |
| --------------- | ------------------------------------------------------------------------- | ------------------------------------ |
| `SettingsState` | themeMode, seedColor, windowStyle, imageBackground, shortcutBindings      | 主题、窗口、背景、快捷键             |
| `BrowserState`  | currentDir, entries, imageFiles                                           | 目录浏览（当前未在 UI 中使用，预留） |
| `ViewerState`   | imageBytes, svgBytes, currentPath, files, currentIndex, imageWidth/Height | 图片加载与导航                       |

## 6. 启动流程

```
main(args)
    ├── WidgetsFlutterBinding.ensureInitialized()
    ├── windowManager.ensureInitialized()
    ├── windowManager.setTitleBarStyle(hidden)        # 自绘标题栏
    ├── windowManager.setMinimumSize(800, 600)
    ├── windowMaximizedNotifier.value = isMaximized() # 同步初始状态
    ├── SettingsService().init()                      # 加载 SharedPreferences
    ├── initialFile = args.first if exists else null  # 命令行参数
    └── runApp(ImagicApp(initialFile, settings))
            ↓
        ViewerScreen(initialFile)
            ├── postFrame → focusNode.requestFocus()
            └── postFrame → ViewerState.openFile(initialFile)  # 若有
```

## 7. 线程模型

- **主 Isolate（UI）**：所有 Widget 渲染、Provider 状态更新、按键事件处理
- **后台 Isolate**：通过 `Isolate.run` 执行图片解码与重编码（`ImageCodecService.bytesToPng`）
- **异步 I/O**：文件读取使用 `dart:io` 的 `Future` API
