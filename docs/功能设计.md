# Imagic 功能设计

## 1. 概述

Imagic 是一款基于 Flutter 构建的 Windows 桌面图片查看器，采用 Material Design 3 视觉风格。当前版本专注于图片浏览体验：高质量的解码性能、平滑的缩放动画、灵活的主题与快捷键定制。编辑、保存、导出等功能为后续规划，本文档仅描述已实现部分，并以「规划中」标记未实现内容。

## 2. 已实现功能

### 2.1 图片打开

| 功能           | 说明                                                           |
| -------------- | -------------------------------------------------------------- |
| 文件对话框打开 | 菜单「文件 → 打开图片…」或菜单栏文件夹按钮，过滤为支持的扩展名 |
| 拖拽打开       | 从资源管理器拖拽文件到窗口任意位置直接打开                     |
| 点击空白打开   | 空状态下点击画布中心区域调用文件对话框                         |
| 命令行参数打开 | 启动时传入文件路径参数，应用启动后自动打开                     |
| 单实例转发     | 已有实例运行时再次打开图片，路径转发给主实例并聚焦窗口         |
| 自动回到查看页 | 处于设置页时收到外部打开请求，自动弹回查看页显示图片           |
| 同目录浏览     | 打开图片时自动加载同目录下所有支持格式的图片列表               |

### 2.2 图片查看

| 功能       | 说明                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| 缩放       | 滚轮 / 菜单「放大」「缩小」，范围 10%~3200%                              |
| 缩放动画   | 缩放操作以视口中心为焦点，播放 200ms `easeOutCubic` 平滑过渡             |
| 平移       | 鼠标拖拽平移，直接透传无动画                                             |
| 实际大小   | 菜单「查看 → 实际大小」，动画回到 100%                                   |
| 适应窗口   | 菜单「查看 → 适应窗口」，动画回到 identity（即 BoxFit.contain 默认状态） |
| 还原浮层   | 缩放或平移后画布底部出现「还原」按钮，点击动画回到默认状态               |
| 翻页导航   | 上一张 / 下一张（菜单栏箭头按钮、画布左右悬浮按钮、键盘 ← →）            |
| 文件信息   | 底部状态栏显示进度（n/total）、文件大小、尺寸（宽×高）、格式             |
| 缩放百分比 | 底部状态栏右侧实时显示当前缩放百分比                                     |

### 2.3 全屏模式

| 功能     | 说明                                                             |
| -------- | ---------------------------------------------------------------- |
| 进入全屏 | 菜单「查看 → 全屏」、F11、底栏全屏按钮                           |
| 退出全屏 | F11、Esc、底栏全屏按钮                                           |
| 全屏提示 | 进入全屏后顶部居中浮现提示条，3 秒后自动滑出消失，告知退出快捷键 |
| 隐藏 UI  | 全屏时通过 `AnimatedSize` 隐藏菜单栏与底部状态栏                 |

**实现说明**：全屏通过 `windowManager.maximize()` / `unmaximize()` 模拟，而非 `setFullScreen(true)`。原因是后者退出时窗口瞬间弹回且会闪现原生标题栏；`maximize` 进出都有平滑动画，代价是任务栏仍可见。

### 2.4 窗口管理

| 功能            | 说明                                                                                 |
| --------------- | ------------------------------------------------------------------------------------ |
| 自绘标题栏      | 隐藏系统标题栏，由 `AppMenuBar` 承担拖拽与按钮区域                                   |
| 窗口控件样式    | 设置中可选 Windows 风格（右上角最小化/最大化/关闭）或 macOS 风格（左上角红黄绿圆点） |
| 拖拽窗口        | 菜单栏空白区域按下即可拖拽窗口                                                       |
| 最小尺寸        | 800×600                                                                              |
| 最大化状态      | 启动时同步当前实际状态，避免 OS 以最大化恢复窗口时图标错位                           |
| 全屏/最大化分离 | 全屏状态与最大化状态用独立 notifier 跟踪，用户主动最大化不会触发全屏                 |

#### 2.5.4 快捷键

共 10 个动作，均支持重新绑定、组合键（Ctrl / Alt / Shift / Meta）与冲突检测：

| 动作       | 默认键 | 动作       | 默认键 |
| ---------- | ------ | ---------- | ------ |
| 打开文件   | Ctrl+O | 上一张图片 | ←      |
| 关闭图片   | Ctrl+W | 下一张图片 | →      |
| 实际大小   | Ctrl+1 | 切换全屏   | F11    |
| 适应窗口   | Ctrl+0 | 退出全屏   | Esc    |
| 放大       | Ctrl+= | 缩小       | Ctrl+- |

- 点击按键徽章弹出绑定对话框，按下组合键即捕获（修饰键实时显示，松开后确认）
- 修饰键（Shift / Ctrl / Alt / Meta）不作为独立按键捕获
- 冲突检测：若与其他动作冲突，弹出警告对话框确认是否仍然绑定
- 已自定义的按键徽章用 tertiary 色高亮，并显示「重置」按钮
- 列表行显示冲突警告图标（Tooltip 说明冲突对象）
- 菜单栏的快捷键提示文本同步当前绑定

#### 2.5.6 更新

| 设置项           | 说明                                                                  |
| ---------------- | --------------------------------------------------------------------- |
| 启动时检查更新   | 开关，默认开启；启动后延迟 800ms 自动检查 GitHub Releases             |
| 更新渠道         | SegmentedButton：正式版 / 所有版本，默认正式版（所有版本含预发行版）   |
| 检查更新         | 手动触发一次检查，结果内联展示（检查中 / 已是最新 / 发现新版本 / 失败）|
| 更新对话框       | 展示版本号、更新日志、下载进度；「下载并更新」按钮下载并安装          |

- 更新资产按当前安装形式分流：MSIX 仅下载 msix；安装版优先 exe > msix > zip；绿色版优先 zip > exe > msix
- 正式版渠道只看无 beta/rc 后缀的 tag；所有版本渠道同时接受正式版与预发行版，取 SemVer 最高者
- 版本比较遵循语义化版本（`0.1.0-beta.2 < 0.1.0`）
- 下载后以 GitHub 提供的 SHA-256（`digest`）校验，不一致则中止并提示
- 安装流程（绿色版 zip）：下载 → 校验 → 生成批处理脚本 → 应用退出，脚本替换文件并重新启动
- 安装流程（exe/msix）：下载 → 校验 → 启动安装程序，由用户接管剩余步骤，应用无需退出
- 仅 Windows 支持；启动时发现新版本自动弹出更新对话框

## 3. 支持的图片格式

| 格式        | 扩展名             | 加载方式                       |
| ----------- | ------------------ | ------------------------------ |
| JPEG        | .jpg / .jpeg       | Isolate 解码重编码为 PNG       |
| PNG         | .png               | 直接读取字节（引擎 C++ 解码）  |
| BMP         | .bmp               | Isolate 解码重编码为 PNG       |
| GIF         | .gif               | Isolate 解码重编码为 PNG       |
| WebP        | .webp              | Isolate 解码重编码为 PNG       |
| PPM/PGM/PBM | .ppm / .pgm / .pbm | Isolate 解码重编码为 PNG       |
| TGA         | .tga               | Isolate 解码重编码为 PNG       |
| SVG         | .svg               | 直接读取字节，flutter_svg 渲染 |

> 保存/导出当前未实现，`kEnabledFormats` 仅列出 JPEG / PNG / BMP / WebP 作为后续导出格式的预设。

## 5. 规划中功能

以下功能在菜单或设置中已有入口或占位，但尚未实现：

- **编辑模式**：裁剪、旋转、翻转、色彩调整、滤镜、绘图标注
- **撤销 / 重做**：操作历史栈
- **保存 / 导出**：另存为、格式转换、质量参数
- **文件面板**：侧边栏目录树 + 缩略图网格

- **最近文件**：记录最近打开的文件
- **配置备份**：导出 / 导入设置 JSON

## 6. 错误处理

- 文件打开失败：通过 `SnackBar` 显示错误信息（3 秒）
- 解码失败：抛出异常被 `ViewerState.openFile` 捕获并写入 `errorMessage`
- 快捷键冲突：绑定前检测，弹出对话框确认
