# Imagic 功能设计

## 1. 概述

Imagic 是一款 Windows 桌面端图片查看与轻量编辑工具，基于 Flutter 构建。支持主流图片格式的浏览、基础编辑调整、绘图标注以及导出保存。

## 2. 功能模块

### 2.1 文件浏览

| 功能 | 说明 |
|------|------|
| 打开文件 | 支持菜单/工具栏/快捷键(Ctrl+O) 打开文件对话框 |
| 双击打开 | 注册文件关联后，在资源管理器中双击图片直接打开 |
| 拖拽打开 | 从资源管理器拖拽图片文件到窗口打开 |
| 目录浏览 | 打开图片时自动加载同目录下所有支持格式的图片 |
| 翻页导航 | 上一张/下一张按钮，键盘 ← → 翻页 |
| 最近文件 | 记录最近打开的 10 个文件 |
| 文件信息 | 显示文件名、尺寸、格式、文件大小 |

### 2.2 图片查看

| 功能 | 说明 |
|------|------|
| 缩放 | 滚轮缩放，范围 10%~3200% |
| 自适应 | Ctrl+0 或按钮自适应窗口大小 |
| 实际尺寸 | Ctrl+1 或按钮 100% 显示 |
| 平移 | 鼠标拖拽平移（图片超出窗口时） |
| 全屏 | F11 全屏/退出全屏 |
| 旋转 | 90°/180°/270° 旋转（查看模式，无损） |
| 幻灯片 | 自动轮播，间隔时间可调 |

### 2.3 图片编辑

#### 基础变换

| 功能 | 说明 |
|------|------|
| 裁剪 | 自由裁剪 / 固定比例裁剪（1:1, 4:3, 16:9 等） |
| 旋转 | 任意角度旋转，步进 1° |
| 翻转 | 水平翻转 / 垂直翻转 |
| 缩放 | 按百分比或像素值缩放图像 |

#### 色彩调整

| 功能 | 说明 |
|------|------|
| 亮度 | -100 ~ +100 滑动调节 |
| 对比度 | -100 ~ +100 滑动调节 |
| 饱和度 | -100 ~ +100 滑动调节 |
| 色相 | 0° ~ 360° 色相偏移 |
| 色阶 | 黑场/灰场/白场三点调节 |

#### 滤镜

| 功能 | 说明 |
|------|------|
| 灰度 | 去色转为灰度图 |
| 反色 | 颜色反转 |
| 模糊 | 高斯模糊，半径可调 |
| 锐化 | 锐化强度可调 |
| 浮雕 | 浮雕效果 |
| 边缘检测 | 边缘提取效果 |
| 像素化 | 马赛克化 |
| 怀旧 | 复古色调 |
| 二值化 | 阈值可调的纯黑白 |

#### 绘图标注

| 功能 | 说明 |
|------|------|
| 画笔 | 自由绘制，支持颜色/粗细/透明度 |
| 形状 | 矩形/椭圆/直线/箭头，支持填充/描边 |
| 文字 | 在图片上添加文字标签，支持字体/大小/颜色 |
| 橡皮擦 | 擦除绘制的标注内容 |

### 2.4 撤销/重做

| 功能 | 说明 |
|------|------|
| 撤销 | Ctrl+Z，无限级撤销 |
| 重做 | Ctrl+Y 或 Ctrl+Shift+Z |
| 操作历史 | 显示操作列表，可跳转到任意历史状态 |
| 重置 | 一键恢复到原始图片 |

### 2.5 导出保存

| 功能 | 说明 |
|------|------|
| 保存 | Ctrl+S，覆盖原文件（格式不变） |
| 另存为 | Ctrl+Shift+S，选择格式和路径 |
| 导出格式 | JPEG / PNG / BMP / WebP |
| 导出参数 | JPEG 质量(1-100)、PNG 压缩级别、WebP 质量 |
| 导出尺寸 | 可选缩放导出尺寸，保持宽高比 |
| 应用编辑 | 导出时应用所有编辑操作和叠加层 |

### 2.6 支持的图片格式

| 格式 | 查看 | 编辑 | 保存/导出 |
|------|------|------|-----------|
| JPEG (.jpg/.jpeg) | ✅ | ✅ | ✅ |
| PNG (.png) | ✅ | ✅ | ✅ |
| BMP (.bmp) | ✅ | ✅ | ✅ |
| GIF (.gif) | ✅ | ✅(静态) | ✅(静态) |
| WebP (.webp) | ✅ | ✅ | ✅ |
| PPM/PGM/PBM (.ppm/.pgm/.pbm) | ✅ | ✅ | ✅ |
| TGA (.tga) | ✅ | ✅ | ✅ |

## 3. 快捷键一览

| 快捷键 | 功能 |
|--------|------|
| Ctrl+O | 打开文件 |
| Ctrl+S | 保存 |
| Ctrl+Shift+S | 另存为 |
| Ctrl+Z | 撤销 |
| Ctrl+Y / Ctrl+Shift+Z | 重做 |
| Ctrl+0 | 自适应窗口 |
| Ctrl+1 | 实际尺寸 100% |
| ← / → | 上一张/下一张 |
| F11 | 全屏切换 |
| Ctrl+E | 进入编辑模式 |
| Esc | 退出编辑 / 退出全屏 |
| Ctrl+C | 复制图片到剪贴板 |
| Ctrl+A | 全选（文件列表） |
