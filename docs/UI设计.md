# Imagic UI 设计

## 1. 总体布局

```
┌──────────────────────────────────────────────────────────┐
│  菜单栏                                                  │
│  [文件(F)] [编辑(E)] [查看(V)] [工具(T)] [帮助(H)]        │
├──────────┬───────────────────────────────────────────────┤
│          │                                               │
│  文件面板 │              图片画布区域                      │
│  (可收起) │       (缩放/平移/自适应)                      │
│          │                                               │
│  📁 目录树│                                               │
│          │                                               │
│  🖼 缩略图│                                               │
│    网格   │                                               │
│          │                                               │
├──────────┴───────────────────────────────────────────────┤
│  状态栏                                                   │
│  imagic_v1.jpg  |  1920×1080  |  85%  |  JPEG  |  2/12   │
└──────────────────────────────────────────────────────────┘
```

### 窗口尺寸

- 默认窗口：1280×720
- 最小窗口：800×600
- 支持最大化/还原

## 2. 查看模式 (Viewer)

### 2.1 查看模式布局

```
┌──────────────────────────────────────────────────────────┐
│  [←] [→]  |  imagic_v1.jpg  |  [🔍+] [🔍-] [100%] [⌂] │
│  [✎ 编辑] [💾 保存] [↗ 导出] [⛶ 全屏] [⋮ 更多]       │
├──────────────────────────────────────────────────────────┤
│                                                          │
│                    ┌──────────────┐                      │
│                    │              │                      │
│                    │   图片内容    │                      │
│                    │   (居中显示)  │                      │
│                    │              │                      │
│                    └──────────────┘                      │
│                                                          │
├──────────────────────────────────────────────────────────┤
│  100%  [══════════●═══════════════]  □ 适应窗口   ═ □ ═  │
└──────────────────────────────────────────────────────────┘
```

### 2.2 工具栏说明

| 控件 | 位置 | 说明 |
|------|------|------|
| ← / → 按钮 | 左上 | 上一张/下一张图片 |
| 文件名 | 左上 | 当前文件名称，下拉可切换同目录文件 |
| 缩放控制 | 右上 | +/- 按钮、缩放百分比下拉、自适应按钮 |
| 编辑按钮 | 右上 | 切换到编辑模式 |
| 保存按钮 | 右上 | 保存当前文件 |
| 导出按钮 | 右上 | 打开导出对话框 |
| 全屏按钮 | 右上 | 全屏/退出全屏 |
| 更多菜单 | 右上 | 复制/打印/文件信息/幻灯片播放 |

### 2.3 缩放滑块

右下角缩放滑块 + 百分比显示：
- 最小值 10%
- 最大值 3200%
- 步进：10%~100% 步进 10%，100%~500% 步进 25%，500%~3200% 步进 100%
- 复选框「适应窗口」：勾选后自动缩放到最佳适应尺寸

### 2.4 交互操作

| 操作 | 效果 |
|------|------|
| 鼠标滚轮 | 以鼠标位置为中心缩放 |
| 鼠标拖拽 | 平移图片（图片大于窗口时） |
| 双击图片 | 切换实际尺寸/自适应窗口 |
| Ctrl+滚轮 | 缩放 |
| 空格拖拽 | 平移（类似 PS 手型工具） |

### 3.4 裁剪交互

选择裁剪工具后，画布上出现裁剪框：
- 八个拖拽手柄（四角+四边中点）
- 选中裁剪框可整体移动
- 按下比例锁定时拖拽自动吸附比例
- 裁剪区域外半透明遮罩
- 确认裁剪后应用，未确认前随时可调整

### 3.5 绘图交互

- 画笔：按下鼠标开始绘制，松开停止，每次拖拽为一个独立路径
- 形状：按下确定起点，拖动确定大小，松开完成绘制
- 文字：点击输入位置，弹出文本编辑框，确认后渲染到画布
- 所有绘制内容独立于像素编辑，可单独选中、移动、删除

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│                    ┌──────────────┐                      │
│                    │              │                      │
│                    │   图片内容    │                      │
│                    │  (全屏居中)   │                      │
│                    │              │                      │
│                    └──────────────┘                      │
```

## 6. 颜色与主题

### 配色方案

| 角色 | 颜色 |
|------|------|
| 主背景 | #1E1E1E (深色) / #F5F5F5 (浅色) |
| 面板背景 | #2D2D2D (深色) / #FFFFFF (浅色) |
| 画布背景 (无图时) | #3D3D3D |
| 画布背景 (有图时) | 棋盘格 #808080/#C0C0C0 |
| 强调色 | #5B8DEF |
| 文本 | #E0E0E0 (深色) / #333333 (浅色) |

### 主题切换

- 支持深色模式/浅色模式
- 跟随系统主题（默认）
- 也可在设置中手动切换

## 7. 布局细节

### 响应式调整

| 窗口宽度 | 行为 |
|----------|------|
| >= 1000px | 完整布局：文件面板 + 画布 + 状态栏 |
| < 1000px | 自动收起文件面板，仅显示画布 |
| < 600px | 精简工具栏（图标模式），状态栏只显示关键信息 |

### 间距规范

- 面板间距：4px
- 工具栏图标间距：8px
- 菜单项间距：2px
- 内边距：12px（面板内容）
- 外边框：0px（无边框，扁平风格）
